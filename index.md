## Comment utiliser ce site ?

- Utilise la barre de recherche en haut de la page pour retrouver rapidement un cours, un terme ou une commande.
- Chaque module de cours se termine par un **quiz** pour t'entraîner avant l'examen.
- Le site est modifiable directement depuis GitHub : consulte la page [+ Ajouter du contenu](ajouter-du-contenu.md) quand tu veux ajouter un nouveau cours, TP, terme ou commande.
